Milk-V Megrez installation

Flash SPI from USB Recovery
---------------------------

1. Extract the Megrez package. Open a terminal in that directory and run:

     sha256sum -c SHA256SUMS

2. Power off the board and set the Recovery/Normal switch to Recovery.
   Connect the debug USB-C port to the host with a data cable and power
   on. Open the serial console at 115200 baud, 8N1, without flow control.

3. When the host shows a disk named ESWIN-2030, copy normal-spi.bin into
   its root directory as a file. USB Recovery trains memory with ECC
   disabled. The next SPI boot uses the saved ECC setting. UEFI starts
   in RAM and initializes the SPI variable store if its header is invalid.

4. Press F9 at the UEFI boot prompt. Wait for "USB Fastboot ready" on
   the serial console. Use the same USB-C cable. On the host, run:

   If several Fastboot devices are connected, use fastboot devices and
   add -s SERIAL to both commands to select the Megrez.

     fastboot getvar product

   Check that the product is Milk-V Megrez, then run:

     fastboot flash spi normal-spi.bin

5. Wait for "SPI firmware verified" and OKAY. Power off, set the switch
   to Normal and power on. Check that F2 opens Setup on the serial
   console. In Normal mode, USB0 serves the Type-A hub. The debug USB-C
   port still provides the serial console.

Update from UEFI Setup
----------------------

Put normal-spi.bin and SHA256SUMS together on a FAT SD card or USB
drive. Press F2, open Firmware Update, select normal-spi.bin and press Y.
Wait for "Firmware written and verified." Then restart in Normal mode.
