Milk-V Megrez installation

Check the extracted package with sha256sum -c SHA256SUMS.

To start firmware from USB, power off the board, select Recovery, connect
the USB-C debug port to the host and power on. Copy normal-spi.bin to the
ESWIN-2030 USB disk as a file. Follow startup on the serial console at
115200 baud, 8N1. The copy starts UEFI in RAM. At startup, UEFI erases
and reinitializes the SPI variable store if its header is invalid.

To install the firmware in SPI, put normal-spi.bin and SHA256SUMS together
on a FAT USB drive or SD card. Press F2, select Firmware Update and choose
the image. After verification, power off, select Normal and power on.

To install through the debug USB-C port, start UEFI from ESWIN-2030
and press F9. On the host, run:

  fastboot getvar product

If the product is Milk-V Megrez, run:

  fastboot flash spi normal-spi.bin

Wait for Fastboot to finish writing and verifying the image.
Power off, select Normal and power on.
In Normal mode, USB0 serves the Type-A hub and the debug USB-C port
provides the serial console.
