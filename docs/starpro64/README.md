# PINE64 StarPro64

This package targets the EIC7700X StarPro64 with 16 or 32 GiB of
LPDDR5 memory.
The board uses a 16 MiB SPI NOR. The firmware image covers the first
8 MiB. The factory records at 0xf80000 and 0xfc0000 remain outside it.

See [INSTALL.txt](INSTALL.txt) for the boot and update procedure.
