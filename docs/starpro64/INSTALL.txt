PINE64 StarPro64 installation

Flash SPI from USB Recovery
---------------------------

1. Extract the StarPro64 package. Open a terminal in that directory and
   run:

     sha256sum -c SHA256SUMS

2. Power off the board. Use the numbers and ON mark printed on SW1.
   Switch 1 sets the least significant bit. ON sets a bit to zero.

     Boot mode       SW1-1   SW1-2   SW1-3   SW1-4   BOOT_SEL[3:0]
     USB Recovery    OFF     OFF     ON      ON      0011
     SPI             ON      OFF     ON      ON      0010

   Select USB Recovery. Connect the host to the lower blue Type-A port
   on J2, closest to the PCB. Use a USB data cable that isolates VBUS
   between the host and the board. Power the board from its own supply.
   Follow UART0 at 115200 baud, 8N1, without flow control.

3. When the host shows a disk named ESWIN-2030, copy normal-spi.bin into
   its root directory as a file. This starts UEFI in RAM. UEFI may
   initialize an invalid SPI variable store during startup.

4. Press F9 at the UEFI boot prompt. Wait for "USB Fastboot ready" on
   UART0. Keep the download cable connected. On the host, run:

   If several Fastboot devices are connected, use fastboot devices and
   add -s SERIAL to both commands to select the StarPro64.

     fastboot getvar product

   Check that the product is Pine64 StarPro64, then run:

     fastboot flash spi normal-spi.bin

5. Wait for "SPI firmware verified" and OKAY. Power off, disconnect the
   download cable and set SW1 to SPI. Power on. Check that F2 opens
   Setup on UART0.

Update from UEFI Setup
----------------------

Put normal-spi.bin and SHA256SUMS together on a FAT SD card or USB drive.
Insert a microSD card before power-on because the slot has no card
detect signal. Press F2, open Firmware Update, select normal-spi.bin and
press Y. Wait for "Firmware written and verified." Then restart in SPI mode.

The eMMC bus supports up to HS200 at 1.8 V.
