PINE64 StarPro64

Check the extracted files with sha256sum -c SHA256SUMS. Use the UART0
console at 115200 baud, 8N1. The package contains one normal-spi.bin
for SPI and temporary BootROM USB boot.

For a first USB boot, power off and set SW1 to ROM USB boot
(BOOT_SEL[3:0] = 0011). USB0 is the Type-A port on J2 wired to pins
2 and 3 on the schematic. Use a data connection that isolates host
VBUS from board VBUS. Power the board from its own supply. When the
ESWIN-2030 recovery disk appears, copy normal-spi.bin to it as a file.

To install from UEFI, place normal-spi.bin and SHA256SUMS on a FAT
SD card or USB drive. Open Firmware Update in Setup and select the
image. After verification, power off, select SPI boot (0010) and power
on. UEFI may initialize an invalid variable store during startup.

The microSD connector has no card detect signal. Insert the card before
power-on for UEFI boot. The eMMC bus supports up to HS200 at 1.8 V.
